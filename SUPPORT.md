# Support

Internet Health Monitor is maintained by one person, in the evenings,
around a day job. This page says what to expect and where to ask.

## What to expect

- **Replies.** Every issue and Discussion is read. Replies are best
  effort; a few days is normal.
- **Reviews.** Pull requests are reviewed on weekends, with about a
  two-week turnaround, one active PR per contributor at a time
  ([CONTRIBUTING.md § Review pace](CONTRIBUTING.md#review-pace)).
- **Fixes.** They land as time allows. A bug report with the diagnostics
  download attached moves fastest, because it needs no back and forth.
- **Closing.** A thread that goes quiet is closed as bookkeeping, not
  rejection; a comment on it is still read and can reopen it
  ([CONTRIBUTING.md § Closing](CONTRIBUTING.md#closing)).

## Where to ask

| Need | Go to |
| ---- | ----- |
| Something is broken | [Troubleshooting](https://github.com/solentlabs/internet_health_monitor#troubleshooting), then a [bug report](https://github.com/solentlabs/internet_health_monitor/issues/new/choose) |
| A question, or an idea to shape before any code | [Discussions](https://github.com/solentlabs/internet_health_monitor/discussions) |
| A security problem | [SECURITY.md](SECURITY.md), never a public issue |

Users also help each other on the
[Home Assistant Community Forum](https://community.home-assistant.io/).
